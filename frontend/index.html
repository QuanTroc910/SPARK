Bước 1: Tải file dữ liệu lên

Chọn file CSV/Excel cần kiểm tra. File được gửi thẳng lên backend Flask (POST /api/upload) — backend đọc file bằng attribute_noise/pipeline.py::load_data() rồi trả về danh sách cột để bạn cấu hình ở Bước 3.

Đang kiểm tra kết nối tới backend…

Bước 2: Chọn hướng xử lý

Noise trong dữ liệu được chia theo 2 hướng, mỗi hướng có bộ luật phát hiện + xử lý riêng (xem CLAUDE.md). Attribute noise code trước, Class noise làm sau.

📊 Attribute Noise

Lỗi ở từng thuộc tính/cột: thiếu giá trị, sai định dạng, ngoài khoảng, giá trị bất thường, không nhất quán, khoảng trắng thừa, trùng dòng — cộng rule mâu thuẫn LOGIC giữa 2 cột.

🏷️ Class Noise

Lỗi ở nhãn/lớp phân loại: nhãn sai, nhãn mâu thuẫn với các thuộc tính khác trong cùng dòng.

Bước 3: Cấu hình noise cho từng cột

Với mỗi cột, chọn đúng kiểu dữ liệu rồi bật các loại noise cần kiểm tra. Các trường tham số (min/max, ngưỡng outlier, danh sách category chuẩn...) chỉ hiện khi phù hợp với kiểu dữ liệu đã chọn.

Chưa có dữ liệu — quay lại Bước 1 để tải file.

Trùng dòng (duplicate_row)

Noise cấp DÒNG — so cả dòng (hoặc 1 nhóm cột chỉ định) với các dòng khác, không thuộc riêng 1 cột nào.

Rule liên cột (tuỳ chọn)

Kiểm tra mâu thuẫn LOGIC giữa 2 cột — vd "tuổi phải ≤ điểm đánh giá" hay "mã nhân viên phải luôn gắn với đúng 1 tên". Bạn tự chọn cột và quan hệ, hệ thống không tự đoán được vì mỗi file dữ liệu có ý nghĩa khác nhau (xem CLAUDE.md mục 7).

Bước 5: Xử lý & xuất file

Với MỖI cặp (cột, loại noise) THỰC SỰ có trong kết quả Bước 4, chọn 1 cách xử lý bên dưới — hành động khả dụng được quyết định theo bảng (dtype, noise_type) trong attribute_noise/attribute_handling.py. Rule liên cột hiện CHƯA hỗ trợ xử lý tự động ở bước này, chỉ 7 loại attribute noise theo cột + duplicate_row.

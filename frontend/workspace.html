Dùng Denoise
từ file bẩn tới file sạch

Từng bước thao tác, từ lúc đăng nhập tới lúc tải file sạch về.

01Bắt đầu nhanh

Làm sạch một file chỉ cần 4 bước:

  1. Đăng nhập. Bấm "Bắt đầu" ở góc phải trên cùng để tạo tài khoản, chỉ cần tên đăng nhập và mật khẩu.
  2. Chọn tool. Mở menu Sản phẩm ở đầu trang rồi bấm tool bạn cần.
  3. Đưa file vào. Ở khung 01 · Đầu vào, kéo thả file hoặc bấm "Dán text" để dán nội dung.
  4. Chạy rồi tải về. Bấm nút chạy, xem bảng ở khung 02 · Kết quả, rồi bấm "Tải xuống CSV".

Không biết dùng tool nào? Nhìn file của bạn đang gặp gì:

  • Dòng lặp lại → Xoá dòng trùng
  • Khoảng trắng thừa ở đầu hoặc cuối ô → Cắt khoảng trắng
  • Ô trống, "NA", "-" → Ô trống
  • Email, số điện thoại, ngày sai khuôn → Sai định dạng
  • Số vô lý như tuổi 210 → Ngoài khoảng (nếu biết khoảng đúng) hoặc Giá trị bất thường (nếu chưa biết)
  • "Nam", "nam", "NAM" lẫn lộn → Không nhất quán
  • Hai cột mâu thuẫn nhau (ngày nghỉ trước ngày vào...) → Quy tắc liên cột
  • Nghi nhãn phân loại bị gán sai → Nhãn sai
  • Cần đổi định dạng file → Chuyển đổi

02Chuẩn bị file

  • Dùng file CSV hoặc Excel (.xlsx, .xls). Riêng Chuyển đổi JSON → CSV nhận .json và .jsonl.
  • Dòng đầu tiên phải là tên cột.
  • CSV nên lưu bằng mã UTF-8 để chữ có dấu không bị lỗi.
  • Denoise đọc mọi giá trị dưới dạng chữ, nên "007" vẫn là "007", không bị đổi thành 7.

03Tự động

Nhóm này không cần khai cột hay tham số. Chọn file, chỉnh vài tuỳ chọn, bấm Chạy.

  • Xoá dòng trùng: để trống ô "Chỉ so theo các cột này" thì so cả dòng, hoặc gõ tên cột (vd email). Chọn giữ bản đầu tiên hay cuối cùng. Chạy xong bấm "Xem các dòng trùng" để kiểm tra.
  • Cắt khoảng trắng: khoảng trắng đầu/cuối luôn được cắt. Tick thêm "Gộp khoảng trắng lặp lại" nếu cần. Bấm "Xem các ô đã sửa" để xem ô nào thay đổi.
  • Ô trống: bảng liệt kê các cột có ô trống. Mỗi cột chọn một cách: Giữ nguyên, Điền từ ô phía trên, Điền tay từng ô, Điền trung bình / trung vị / KNN (cột số), Điền giá trị phổ biến nhất (cột nhóm) hoặc Xoá cả dòng. Cột để "Giữ nguyên" không bị đụng tới.
  • Sai định dạng: Denoise đoán kiểu từng cột và hiện trong bảng "Kiểu dữ liệu từng cột", đoán sai thì chọn lại. Sau đó chọn "Chỉ báo", "Để trống ô sai" hoặc "Xoá cả dòng" rồi Chạy.
Mẹo

Thứ tự gợi ý: Cắt khoảng trắng, Sai định dạng, Ô trống, cuối cùng Xoá dòng trùng. Làm sạch trước thì việc so khớp dòng trùng mới chính xác.

04Chuyển đổi

  • Đổi dấu phân cách CSV: chọn "Dấu phân cách gốc" (hoặc Tự nhận diện) và "Dấu phân cách mới", bấm Chuyển đổi.
  • CSV → JSON: chọn dòng đầu có phải tên cột không, kiểu kết quả Objects hoặc Arrays, bấm Chuyển đổi. Kết quả JSON hiện dạng chữ.
  • JSON → CSV: dán JSON hoặc thả file .json / .jsonl, chọn dấu phân cách đầu ra, bấm Chuyển đổi. Object lồng nhau thành cột "cha.con".

Kết quả tải về bằng nút "Tải xuống" ở góc khung 02.

05Tool cần cấu hình

Bốn tool này cần bạn khai cột và tham số, nên chạy hai nhịp: Phát hiện để xem lỗi, rồi Áp dụng để sửa.

  1. Chọn file hoặc dán text. Danh sách cột hiện ra sau khi Denoise đọc xong.
  2. Khai cột và tham số. Bấm "＋ Thêm cột kiểm tra" để kiểm nhiều cột một lượt.
  3. Phát hiện. Ô lỗi được tô màu ở khung bên phải, bảng "Lỗi theo từng cột" cho biết mỗi cột có bao nhiêu lỗi. Lúc này chưa sửa gì.
  4. Chọn cách xử lý cho từng cột rồi bấm Áp dụng. Cột để "— Chọn cách xử lý —" thì không bị đụng tới. Nếu có xoá dòng, Denoise báo trước số dòng và hỏi xác nhận.
  • Ngoài khoảng: gõ giá trị nhỏ nhất và lớn nhất hợp lệ (vd tuổi từ 18 đến 65). Có thể kéo về biên, điền lại hoặc xoá dòng.
  • Giá trị bất thường: chọn IQR và / hoặc Z-score (mặc định 1.5 và 3). Cột mà đa số ô cùng một giá trị sẽ có cảnh báo vàng.
  • Không nhất quán: gõ danh sách giá trị chuẩn, cách nhau bởi dấu phẩy (vd Nam, Nữ). Các biến thể như "nam", " NAM " được đưa về giá trị chuẩn.
  • Quy tắc liên cột, tab Biểu thức: bấm tên cột và các nút để ghép điều kiện mọi dòng phải thoả, vd tuoi >= 18 và tuoi <= 65 hoặc phong_ban = "Sales" => luong >= 10000000 (nút "thì =>" nghĩa là "nếu … thì …"). Dòng chữ xanh hoặc đỏ dưới ô cho biết biểu thức đúng hay sai ngay khi gõ.
  • Quy tắc liên cột, tab Phụ thuộc hàm: chọn cột xác định A và các cột phụ thuộc (vd mã nhân viên → tên). Denoise gợi ý ô nào nghi sai, rồi bạn chọn sửa về giá trị phổ biến, xoá dòng nghi sai, xoá cả dòng hoặc giữ nguyên.
Lưu ý

Nếu bạn đổi cấu hình sau khi Phát hiện, nút Áp dụng bị khoá cho tới khi bấm Phát hiện lại.

06Nhãn sai

Dùng khi file có một cột nhãn (vd loại khách hàng) và bạn nghi vài dòng bị gán sai nhãn. Denoise chạy Confident Learning (Random Forest) và Mutual k-NN rồi gộp thành một danh sách. Có 4 bước:

  1. Tải file. Chọn file CSV hoặc Excel rồi bấm "Tải lên & tiếp tục".
  2. Nhãn & đặc trưng. Chọn cột nhãn, rồi tick các cột SỐ dùng để dự đoán nhãn (cột chữ chưa được hỗ trợ nên bị khoá). Bấm "Phát hiện nhãn sai"; file lớn có thể mất vài phút. Denoise tự bỏ cột thừa trước khi chạy (cột hằng, mã định danh, trùng thông tin, và cột Boruta thấy không liên quan tới nhãn); cột nào bị bỏ sẽ được ghi ở bước Kết quả.
  3. Kết quả. Đọc cảnh báo và bước chuẩn bị dữ liệu (cột nào bị bỏ, dòng nào gộp hoặc mâu thuẫn) trước. Cảnh báo đỏ nghĩa là danh sách rất khó tin, hãy chọn lại cột đặc trưng. Cột «Cùng nghi» cho biết phương pháp nào cũng gắn cờ dòng đó; bấm "Xem thêm" để xem mức tin cậy và danh sách riêng của từng phương pháp.
  4. Xử lý. Mỗi dòng nghi ngờ có 3 cách: giữ nguyên, xoá dòng hoặc sửa nhãn (theo gợi ý hoặc sang nhãn khác đã có). Có thể gán hàng loạt theo hướng đổi nhãn và mức đáng ngờ. "Áp dụng" chạy thử và hỏi xác nhận trước khi ghi, hoàn tác được; xong thì xuất file CSV.

07Nối tiếp và hoàn tác

  • Chạy xong, kết quả trở thành đầu vào cho tool kế tiếp. Bấm một mục trong "Xong · xử lý tiếp bằng" để chuyển tool mà không phải tải file lại; bấm "Nhãn sai" để đưa kết quả sang tìm nhãn sai.
  • Dải đen phía trên ghi các bước đã qua, kèm 3 nút: "Tải file khác", "Hoàn tác bước cuối" (lùi tối đa 5 bước) và "Bắt đầu lại từ gốc".
  • File gốc không bị đụng tới. "Tải xuống CSV" luôn lấy kết quả mới nhất.

08Câu hỏi thường gặp

Vì sao phải đăng nhập?

Không. Chạy python3 app.py rồi mở http://localhost:5000.

01File của bạn đi đâu

File được đọc vào bộ nhớ của backend, không ghi ra đĩa và không gửi tới dịch vụ bên ngoài.

  • Bản gốc không bao giờ bị sửa.
  • Tự động và Chuyển đổi không giữ lại gì sau khi trả kết quả.
  • Khởi động lại server là file trong bộ nhớ biến mất.

02Mật khẩu

Mật khẩu được băm bằng thư viện Werkzeug trước khi lưu vào SQLite. Server không giữ bản rõ.

  • Sai tên đăng nhập hay sai mật khẩu đều báo cùng một câu.
  • Tên đăng nhập từ 3 ký tự, mật khẩu từ 6 ký tự.

03Phiên đăng nhập

Đăng nhập được giữ bằng cookie phiên do Flask ký. Đăng xuất là xoá phiên ngay.

04Quyền sở hữu file

Mỗi file gắn với tài khoản đã tải lên. File của tài khoản khác được trả lời như file không tồn tại.

05Biểu thức quy tắc liên cột

Biểu thức được đọc bằng bộ phân tích tự viết, chỉ hiểu so sánh, phép tính và vài hàm cố định. Không dùng eval().

06Giới hạn đã biết

  • Khởi động lại server thì mọi người phải đăng nhập lại.
  • Chưa có quên mật khẩu, xác thực email hay giới hạn số lần đăng nhập sai.
  • Chạy cục bộ chưa có HTTPS. Đưa lên mạng cần đặt sau reverse proxy có TLS.

02File bạn tải lên

File chỉ nằm trong bộ nhớ backend khi đang xử lý, chỉ tài khoản của bạn truy cập được.

  • Khởi động lại server là file biến mất.
  • Khi tìm nhãn sai, Denoise huấn luyện mô hình trên dữ liệu của bạn và bỏ mô hình ngay sau khi trả kết quả.

[ Bước 3 / 5 ]

Cấu hình noise cho từng cột

Với mỗi cột, kiểm tra kiểu dữ liệu (Denoise đã đoán sẵn, sửa được) rồi bật các loại nhiễu cần dò. Tham số (min/max, ngưỡng outlier, danh sách giá trị chuẩn...) chỉ hiện khi hợp với kiểu đã chọn.

Chưa có dữ liệu. Quay lại Bước 1 để tải file.

Dòng trùng

Nhiễu cấp dòng: so cả dòng (hoặc một nhóm cột chỉ định) với các dòng khác, không thuộc riêng cột nào.

Quy tắc liên cột (tuỳ chọn)

Kiểm tra mâu thuẫn logic giữa hai cột, ví dụ "ngày bắt đầu phải trước ngày kết thúc" hay "mã nhân viên luôn gắn với đúng một tên". Bạn tự chọn cột và quan hệ vì mỗi file có ý nghĩa khác nhau.

Chọn cột làm nhãn và các cột số làm đặc trưng.

Xử lý

Bấm tên mỗi nhóm để xem từng dòng, tick dòng muốn xử lý, chọn cách xử lý cho từng dòng rồi bấm "Áp dụng". Không cần xử lý hết các nhóm cùng lúc. Xoá dòng luôn được chạy thử và hỏi lại; mọi bước đều hoàn tác được. Quy tắc liên cột chưa hỗ trợ xử lý tự động. Xong thì bấm "Xuất file CSV" ở cuối trang.
